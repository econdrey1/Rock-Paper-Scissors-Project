I created this Rock Paper Scissors game as a beginner Python project to practice working with user input, conditionals, lists, and random numbers.
The player chooses Rock, Paper, or Scissors by entering a number. The computer then randomly chooses its own option. The program compares both choices and tells the player whether they won, lost, or tied.
What I Learned
While working on this project, I practiced:
- Using input() to get information from the user
- Converting user input into an integer
- Using lists to store Rock, Paper, and Scissors
- Using the random module
- Using if, elif, and else statements
- Comparing the player's choice to the computer's choice
- Handling invalid user input
How It Works
The player enters:
- 0 for Rock
- 1 for Paper
- 2 for Scissors
The computer randomly chooses a number from 0 to 2. The program then compares the two choices and displays the result.
